# Baseball bat

User-supplied `Bat.obj` + `wood5.png` from
`/mnt/storage/Bunker Game/models/NEW MODELS/Baseball Bat/` (the OBJ's `Bat.mtl` was
not supplied, so the wood texture is bound to a new material, roughness 0.62).
Source author/license not in the folder; keep the original alongside the project.

Conversion (Blender 5.1.2): transforms applied, uniformly scaled to 0.84 m, knob
(thinner) end toward +Z, barrel along Godot -Z, origin at the grip 10% up from the
knob. Topology and UVs untouched. GLB embeds the texture as JPEG.
